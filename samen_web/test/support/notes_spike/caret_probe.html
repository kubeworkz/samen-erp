Caret probe (WS-Notes P0)

Measures the ONE property a server cannot see: if a focused <textarea> has its value re-written with the same string — the worst case of LiveView echoing a debounced change back — does the caret stay where the user put it? The second half of the probe writes a different string on purpose: that is the positive control, and it must move the caret to the end. Without the control, "the caret did not move" would be unfalsifiable.

Driven by the agent through the preview console; see docs/ws-notes/p0-findings.md.
